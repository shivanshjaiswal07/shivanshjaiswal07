## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for loading external fonts and icons

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/shivanshjaiswal07/codetutor.git
   cd codetutor
   ```

2. **Open the project**
   - Open `index.html` in your preferred web browser
   - Or use a local server for better development experience

3. **Alternative: Run with local server**
   ```bash
   # Using Python (if installed)
   python -m http.server 8000

   # Using Node.js (if installed)
   npx serve .

   # Or simply open index.html in browser
   ```

4. **Access the website**
   - Open your browser and navigate to `http://localhost:8000` (if using server)
   - Or directly open `index.html` in your browser

### Course Selection Process
1. Browse available courses in the Courses section
2. Click "Enroll Now" on your preferred course
3. Review order summary in the Payment section

5. Complete secure payment processing
6. Receive instant access to course materials
